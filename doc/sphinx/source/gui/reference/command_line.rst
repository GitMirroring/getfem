Command line
============

``getfem_gui COMMAND ...`` (the command installed by ``pip install -e gui``), or ``python -m getfem_gui COMMAND ...`` from the ``gui`` directory. Without a command (no argument, or a model file and the options of ``gui``), the graphical interface opens.

new
--------

Create a starting model.

.. code-block:: text

   getfem_gui new [-h] model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file

validate
--------

Check a model, including its gwfl expressions.

.. code-block:: text

   getfem_gui validate [-h] [--python PYTHON] model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file
   * - ``--python``
     - Python interpreter that provides GetFEM

mesh
--------

Build the meshes (cached).

.. code-block:: text

   getfem_gui mesh [-h] [-m MESH] [--force] [-w WORKDIR] [--python PYTHON]
                          model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file
   * - ``-m, --mesh``
     - mesh name (repeatable)
   * - ``--force``
     - ignore the cache
   * - ``-w, --workdir``
     - working directory (default: <model>\_run/)
   * - ``--python``
     - Python interpreter that provides GetFEM
