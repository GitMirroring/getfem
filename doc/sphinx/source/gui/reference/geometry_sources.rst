Geometry sources
================

The source of a geometry says how it is defined. The form of a geometry node shows the fields below; the key is the one of the ``source`` object of the geometry in the model file.

   :header-rows: 1
   :widths: 20 50 30

   * - Source
     - Description
     - Meshers
   * - :ref:```box`` <gui-ref-source-box>`
     - box
     - ``structured``, ``getfem``, ``gmsh``, ``netgen``
   * - :ref:```csg`` <gui-ref-source-csg>`
     - constructive geometry (csg)
     - ``getfem``, ``gmsh``, ``netgen``
   * - :ref:```cad`` <gui-ref-source-cad>`
     - CAD file (STEP, IGES, BREP)
     - ``gmsh``, ``netgen``
   * - :ref:```mesh_file`` <gui-ref-source-mesh_file>`
     - mesh file (.msh)
     - ``import``
   * - :ref:```curve`` <gui-ref-source-curve>`

     - ``getfem``
   * - :ref:```surface`` <gui-ref-source-surface>`

     - ``getfem``, ``gmsh``, ``netgen``
   * - :ref:```swept_surface`` <gui-ref-source-swept_surface>`

.. _gui-ref-source-curve:

curve: curve (2D or 3D)
-----------------------

Meshers: ``getfem``.

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - Field
     - Key
     - Value
   * - Name
     - ``geometries.0.name``
     - name
   * - Dimension of the space
     - ``dim``
     - one of ``2`` (2D), ``3`` (3D)
   * - Points
     - ``points``
     - table of the points: coordinates, and the point an arc goes through. The curve goes through the points in order: a segment to the next one, or an arc of circle through the point given in the last column ("x, y" or "x, y, z"; empty: a segment).
   * - Closed
     - ``closed``
     - one of ``false`` (no), ``true`` (yes). Closed: the last point is joined to the first one.

The ends of an open curve are the built-in selections start and end.

Built-in selections: ``all``, ``boundary``, ``start``, ``end``.

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

     - name

     - numbers or expressions of parameters, one per coordinate
   * - Axis x
     - ``axes.0``
     - numbers or expressions of parameters, one per coordinate
   * - Axis y
     - ``axes.1``
     - numbers or expressions of parameters, one per coordinate
   * - Height
     - ``height``
     - number or GWFL expression. Height along the normal: a number or an expression of the local coordinates x, y and the parameters ("0.2\*sqr(x)").

The flat domain (2D shape below) is drawn and its selections are defined in the local coordinates (x, y).

Built-in selections: ``all``, ``boundary``.
