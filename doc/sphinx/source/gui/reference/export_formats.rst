Export formats
==============

The suffix of the file gives the format.

Geometries
----------

.. list-table::
   :header-rows: 1
   :widths: 15 45 40

   * - Suffix
     - Format
     - Geometries
   * - ``.svg``
     - SVG outline
     - 2D
   * - ``.dxf``
     - DXF outline
     - 2D
   * - ``.stl``
     - STL surface
     - 3D
   * - ``.obj``
     - OBJ surface
     - 3D
   * - ``.ply``
     - PLY surface
     - 3D
   * - ``.vtp``
     - VTK surface
     - 3D
   * - ``.step``
     - STEP (Gmsh/OpenCASCADE)
     - 2D, 3D (requires the gmsh module)
   * - ``.stp``
     - STEP (Gmsh/OpenCASCADE)
     - 2D, 3D (requires the gmsh module)
   * - ``.iges``
     - IGES (Gmsh/OpenCASCADE)
     - 2D, 3D (requires the gmsh module)
   * - ``.igs``
     - IGES (Gmsh/OpenCASCADE)
     - 2D, 3D (requires the gmsh module)
   * - ``.brep``
     - BREP (Gmsh/OpenCASCADE)
     - 2D, 3D (requires the gmsh module)
