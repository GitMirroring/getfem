Command line
============

``getfem_lab COMMAND ...`` (the command installed by ``pip install -e lab``), or ``python -m getfem_lab COMMAND ...`` from the ``lab`` directory. Without a command (no argument, or a model file and the options of ``gui``), the graphical interface opens.

new
--------

Create a starting model.

.. code-block:: text

   getfem_lab new [-h] model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file

validate
--------

Check a model, including its gwfl expressions.

.. code-block:: text

   getfem_lab validate [-h] [--python PYTHON] model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file
   * - ``--python``
     - Python interpreter that provides GetFEM

mesh
--------

Build the meshes (cached).

.. code-block:: text

   getfem_lab mesh [-h] [-m MESH] [--force] [-w WORKDIR] [--python PYTHON]
                          model

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file
   * - ``-m, --mesh``
     - mesh name (repeatable)
   * - ``--force``
     - ignore the cache
   * - ``-w, --workdir``
     - working directory (default: <model>\_run/)
   * - ``--python``
     - Python interpreter that provides GetFEM

gui
--------

Open the graphical interface (requires pyside6).

.. code-block:: text

   getfem_lab gui [-h] [--python PYTHON] [--no-splash] [model]

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``model``
     - the model file
   * - ``--python``
     - Python interpreter that provides GetFEM
   * - ``--no-splash``
     - no start-up window (also: environment variable GETFEM\_LAB\_NO\_SPLASH)

install-desktop
---------------

Linux: install the desktop file and the icon of the interface (~/.local/share), which opens it as now (interpreter, pythonpath).

.. code-block:: text

   getfem_lab install-desktop [-h] [--python PYTHON] [--uninstall]

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Argument
     - Meaning
   * - ``--python``
     - Python interpreter that provides GetFEM (given to the interface)
   * - ``--uninstall``
     - remove them
